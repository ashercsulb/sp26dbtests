Reference the following tutorial:
https://github.com/ashercsulb/isx45-IntAppDev/blob/main/tutorials/nodepostgres_020.MD

You will need to make a connection to your own PostgreSQL database.
Complete the following:
1. Create a .env file
2. Enter the following key (environment variable):
   DATABASE_URL
3. Assign it your connection information.  For example (quotes optional):
   DATABASE_URL="postgresql://neondb_owner:YourPassword@ep-odd-flower-a6xue31w-pooler.us-west-2.aws.neon.tech/neondb"

To run the application
1. Install the dependencies
   npm Install
2. Run the application
   npm start
